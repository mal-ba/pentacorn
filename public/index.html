HOW IT WORKS

세 단계면 충분합니다

패션 지식이 없어도 괜찮아요. 사진 한 장에서 완성된 도면까지, 복잡한 과정을 단순하게 만들었습니다.

01 · Scan

내 몸을 그대로

전신 사진 한 장으로 비대칭·흉터까지 반영한 나만의 3D 아바타를 생성합니다.

02 · Design

탭 몇 번으로 완성

사전 제작된 스타일 템플릿 위에서 컬러·소재·핏을 실시간으로 조정합니다.

03 · Export

실제 제작으로 연결

완성된 디자인을 재단 가능한 2D 패턴 PDF로 변환하고, 제작 파트너에게 바로 전달합니다.

PRODUCT

제품 구성

UNEXPOSED는 3가지 핵심 기능으로 이루어져 있습니다. 신체 스캔부터 실제 제작 도면까지 하나의 흐름으로 이어집니다.

Core 01

Hi-Fi 신체 스캔

전신 사진 한 장으로 비대칭·비정형 체형과 흉터까지 정교하게 반영하는 개인별 3D 아바타를 생성합니다. 표준 체형만 지원하는 기존 패션 소프트웨어와 가장 크게 갈라지는 지점이에요.

Core 02

실시간 커스터마이징

사용자 체형에 맞춰 옷감의 물리적 움직임(드레이핑)을 화면에서 실시간으로 조정합니다. 컬러·소재·핏·장식을 마우스 클릭 몇 번으로 바꿀 수 있어요.

Core 03

2D 패턴 변환

완성한 디자인을 실제 제작·재단이 가능한 의류 도면 파일로 즉시 변환합니다. 등급에 따라 도면만 받거나, 완제품 배송까지 이어집니다.

지원 환경

웹 브라우저와 모바일 앱(iOS·Android)에서 동일한 프로젝트로 이어서 작업할 수 있습니다. 모바일에서는 신체 스캔·간단 수정, 데스크탑에서는 정밀 커스터마이징에 적합하게 UI가 최적화됩니다.

원단·소재 구성

베이직(면·저지 등 기본 소재), 프리미엄(고급 원단), 스페셜(가죽·특수 직물) 3단계로 원단 등급을 나누고, 등급별로 실제 제작 견적이 달라집니다. 등급 선택은 커스터마이징 단계에서 바로 확인할 수 있어요.

데이터 프라이버시

업로드한 신체 사진과 스캔 데이터는 저장하지 않는 제로 포토 리텐션 정책을 기본 적용합니다. 아바타 생성 즉시 원본 이미지는 삭제됩니다.

차별점

고난도 3D 그래픽 숙련도가 필요한 CLO·Marvelous Designer와 달리, 2D 벡터 왜곡 + AI 라인 분리 하이브리드 방식으로 패션 지식이 없어도 누구나 쉽게 디자인할 수 있습니다.

서비스 이용약관 · 신체 데이터 동의

UNEXPOSED는 신체 스캔 기반 맞춤 의류 디자인 서비스입니다. 서비스 이용 시 다음 사항에 동의해야 합니다. (1) 본 서비스는 데모 버전이며 실제 약관은 추후 정식 서비스 출시 시 변호사 검토를 거쳐 제공됩니다. (2) 이용자는 본인의 신체 정보를 자발적으로 입력합니다. (3) 계정 및 결제 정보는 관련 법령에 따라 안전하게 관리됩니다.
신체 데이터 수집·보관 동의 (선택)

동의하면 촬영한 사진과 입력한 키 정보가 서버에 저장되어, 아바타 정확도 개선 등 서비스 향상에 활용돼요. 동의하지 않아도 스캔·아바타 생성 기능은 그대로 사용할 수 있고, 이 경우 데이터는 화면에만 표시되고 저장되지 않아요. 동의는 언제든 이 화면에서 다시 바꿀 수 있고, 철회하면 그동안 저장된 데이터도 즉시 삭제돼요.
